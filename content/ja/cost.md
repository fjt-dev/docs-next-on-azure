デプロイの費用は、アクセス数によって変わります。このページでは、何に課金されるか、Azure で何を実測したか、アクセス数ごとの請求額の目安を示します。試算は、1 つのサイト(このドキュメントサイト)の実測から作ったもので、請求額ではありません。Azure Cost Management の金額とは、まだ照らし合わせていません。

## 何に課金されるか

| リソース | 課金の単位 |
| --- | --- |
| 関数アプリ(Flex Consumption) | 実行回数と、メモリ × 実行時間(GB 秒)。月ごとの無料枠を超えた分です。常時稼働インスタンスは、常に課金されます([ADR-0013](./plan/decisions.md#adr-0013-cold-start-always-ready-instances-first-no-timer-warmer-yet)) |
| Application Insights と Log Analytics | 取り込んだデータ量(GB)。月ごとの無料枠を超えた分です |
| ストレージアカウント | 取引の回数と容量 |
| 外向きのデータ転送 | インターネットへ送った GB。最初の一定量は無料です |
| Azure Front Door Standard(任意) | プロファイルごとの基本料金と、リクエストとデータ |

静的ファイルを含めて、すべてのリクエストが関数を実行します。`/_next/static/*` は、`Cache-Control: public, max-age=31536000, immutable` で返すので、ブラウザは各ファイルを 1 回だけ取得します。`public/` のファイルは、リクエストのたびに再検証されます([ADR-0020](./plan/decisions.md#adr-0020-static-files-stay-with-the-function-cost-options-first-measure-later))。

## Azure での実測

ドキュメントサイトを、2026-11-10 に 2 回デプロイしました(Flex Consumption、japaneast、Next.js 15.5.29)。1 つは既定の設定、もう 1 つはメモリ 512 MB です。スクリプトで、それぞれに 300 回の訪問を行いました。3 割は、ページと 10 個の静的ファイルを取る初回訪問で、残りはページだけを取りました。1 回の実行は、1,260 リクエスト、55.7 MB です。

| | 実測 |
| --- | --- |
| 1 訪問あたりのリクエスト数とデータ量 | 4.2 リクエスト、186 KB |
| 1 リクエストあたりの実行時間(2048 MB) | 0.106 GB 秒(約 53 ms) |
| 1 リクエストあたりの実行時間(512 MB) | 0.105 GB 秒(約 209 ms)。GB 秒は同じで、リクエストの時間が 4 倍 |
| 1 リクエストあたりの Application Insights のデータ量(既定) | 約 4.1 KB(1,550 リクエストに対して、トレース 3,561 件で 4.19 MB、リクエスト 1,550 件で 2.13 MB、メトリクス 146 件) |
| 1 リクエストあたりの Application Insights のデータ量(`--request-telemetry errors`) | 約 0.63 KB(1,260 リクエストに対して、トレース 560 件とメトリクス 56 件で 0.79 MB) |
| ストレージの取引 | デプロイを含む全体で数千回。費用としては無視できる量 |

テレメトリの大半は、リクエストの記録ではなく、関数の「Executing」と「Executed」のメッセージです。`--request-telemetry errors` は、`Host.Results` を `Error` に、`Function.server` を `Warning` にします。アプリ設定の名前にはピリオドが含まれますが、Flex Consumption で動作します。

## アクセス数ごとの試算

ドキュメントサイトのような、1 訪問あたり 4.2 リクエスト、186 KB のサイトを想定しています(2048 MB で実測)。単価は、2026-11-10 時点の日本東の Azure の小売価格(USD)です。実行 100 万回あたり 0.40、1 GB 秒あたり 0.000026、Log Analytics が 1 GB あたり 3.34、Blob の読み取りが 1 万回あたり 0.004、外向きのデータ転送が 1 GB あたり 0.11(最初の約 100 GB は無料のように見えますが、**段階の大きさは未確認**)です。無料枠は、月 250,000 回の実行、100,000 GB 秒、Log Analytics の 5 GB で、Azure の文書から取ったもので、価格表では再確認していません。

| 月間の訪問数 | 関数 | Application Insights(既定) | Application Insights(`errors`) | 外向きのデータ転送 | 合計(既定) | 合計(`errors`) |
| --- | --- | --- | --- | --- | --- | --- |
| 1 万 | 0 | 0 | 0 | 0 | 約 0 | 約 0 |
| 10 万 | 0.1 | 0 | 0 | 0 | 約 0.2 | 約 0.2 |
| 100 万 | 10.5 | 41 | 0 | 9.5 | 約 62 | 約 22 |
| 1,000 万 | 130 | 558 | 70 | 194 | 約 900 | 約 410 |

ストレージは、100 万訪問で約 1.5 ドル加わります。常時稼働インスタンスを 1 台置くと、2048 MB で月約 21 ドルの基本料金が加わります。リクエストの多いサイトや、1 訪問あたりのデータが多いサイトは、費用が増えます。逆なら、減ります。ご自分のページのリクエスト数とキロバイト数で、表を拡大縮小してください。

月 10 万訪問までは、無料枠の中か、数ドルです。それを超えると、削減しなければ Application Insights が請求の最大の部分になり、次が関数、その次が外向きのデータ転送です。

## 費用を下げる方法

| 方法 | 効果 | 状態 |
| --- | --- | --- |
| `deploy --request-telemetry errors` | Application Insights のデータが 85% 減ります。成功したリクエストは、そこに出なくなります | **Verified (Azure)**。効果を実測しました |
| 1 訪問あたりのリクエストを減らす | `/_next/static/*` を Blob か Front Door から配信して、静的ファイルを関数から外します(Standard の基本料金は定価で月約 35 ドル、2026-11-07 に確認。外向きのデータ転送もここで課金されます) | 未実装([ADR-0020](./plan/decisions.md#adr-0020-static-files-stay-with-the-function-cost-options-first-measure-later))。試算では、月数十万訪問からで意味が出ます |
| `deploy --max-instances <n>` | 急な負荷や悪用の最悪の場合を、上限で抑えます(既定 20) | テンプレートは受け付けました。効果は測っていません |
| `deploy --cache-retention-days <n>` | `n` 日後に、キャッシュの内容と、古いビルドの内容を削除します(既定 30) | ルールは Azure で作られました(2026-11-10)。削除されるところは見ていません |
| `deploy --memory 512` | **この負荷では効果なし**: リクエストの時間が 4 倍になり、GB 秒は同じで、インスタンス数が増えました | 実測。512 MB での `sharp` による画像は、試していません |
| `--always-ready` を 0 のままにする | 常時稼働インスタンスは、2048 MB で月約 21 ドルかかります。コールドスタート(2.4 秒が 0.15 秒)はなくなります | 費用は価格表から計算、コールドスタートは実測 |

## 測っていないこと

- 請求額: Azure Cost Management の金額は、まだ読んでいません。実行は短く、ドキュメントサイトで約 90 分です。
- 実際のサイトのアクセス: 訪問はスクリプトで、4 つずつ行いました。動的なページ、画像、Server Actions は、負荷に含めていません。
- 無料の最初の部分を超えた外向きのデータ転送の単価と、Table Storage の単価。
