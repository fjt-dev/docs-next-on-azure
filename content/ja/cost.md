デプロイの費用は、トラフィックによります。このページは、何に課金されるか、何を測定したか、トラフィックごとの請求がどうなるかを示します。見積もりは、1 つのサイト(このドキュメントサイト)の測定から出したもので、請求額ではありません。

## 何に課金されるか

| リソース | 課金の単位 |
| --- | --- |
| Function App([Flex Consumption](https://learn.microsoft.com/azure/azure-functions/flex-consumption-plan?wt.mc_id=studentamb_679600)) | 実行回数と、メモリ × 実行時間(GB 秒)。毎月の無料枠を超えた分。常時稼働のインスタンスは、継続的に課金されます |
| Application Insights と Log Analytics | 取り込んだデータ(GB)。毎月の無料枠を超えた分 |
| ストレージアカウント | トランザクションと容量 |
| アウトバウンドのデータ | インターネットに送った GB。最初の一部は無料 |
| [Azure Front Door](https://learn.microsoft.com/azure/frontdoor/front-door-overview?wt.mc_id=studentamb_679600) Standard(省略可) | プロファイルごとの基本料金と、リクエストとデータ |

すべてのリクエストが関数を実行します(静的ファイルも含みます)。`/_next/static/*` は `Cache-Control: public, max-age=31536000, immutable` で送られるので、ブラウザーは各ファイルを 1 回だけ取得します。`public/` のファイルは、リクエストのたびに再検証されます。

## 測定したこと

ドキュメントサイトを、Japan East の Flex Consumption にデプロイし、スクリプトで、それぞれに 300 回の訪問を行いました。30% は、ページと 10 個の静的ファイルを取得する最初の訪問で、残りは、ページだけを取得しました。

| | 測定値 |
| --- | --- |
| 1 訪問あたりのリクエスト数とデータ量 | 4.2 リクエスト、186 KB |
| 2048 MB での 1 リクエストあたりの実行時間 | 約 0.05〜0.1 GB 秒(26〜106 ms) |
| 1 リクエストあたりの Application Insights のデータ量(既定) | 約 4 KB |
| 1 リクエストあたりの Application Insights のデータ量(`--request-telemetry errors`) | 約 0.6 KB |
| ストレージのトランザクション | テスト全体で数千回(デプロイを含む)。費用は無視できます |

512 MB では、同じリクエストが約 4 倍かかり、GB 秒は同じで、インスタンス数が増えました。この種の負荷では、小さいサイズにしても、費用は下がりません。デプロイの直後のリクエストには、新しいインスタンスの起動が含まれるので、この数字は、動き続けるサイトの上限です。テレメトリの大部分は、関数の「Executing」と「Executed」のメッセージで、`--request-telemetry errors` が、これを除きます。

## トラフィック別の見積もり

ドキュメントのようなサイトで、1 訪問あたり 4.2 リクエストと 186 KB(2048 MB)の場合です。価格は、2026-11-10 の Japan East の Azure のリテール価格(USD)です。100 万実行あたり 0.40、1 GB 秒あたり 0.000026、Log Analytics が 1 GB あたり 3.34、アウトバウンドのデータは、最初の無料の一部のあと、1 GB あたり 0.11 です。無料枠は、毎月、25 万回の実行、10 万 GB 秒、Log Analytics の 5 GB です。

| 月の訪問数 | 関数 | Application Insights(既定) | Application Insights(`errors`) | アウトバウンドのデータ | 合計(既定) | 合計(`errors`) |
| --- | --- | --- | --- | --- | --- | --- |
| 1 万 | 0 | 0 | 0 | 0 | 約 0 | 約 0 |
| 10 万 | 0.1 | 0 | 0 | 0 | 約 0.2 | 約 0.2 |
| 100 万 | 10.5 | 41 | 0 | 9.5 | 約 62 | 約 22 |
| 1,000 万 | 130 | 558 | 70 | 194 | 約 900 | 約 410 |

100 万訪問では、ストレージが約 1.5 USD 加わります。常時稼働のインスタンスは、2048 MB で月に約 21 USD 加わります。リクエストやデータが多いサイトは、費用が増えます。自分のページのリクエスト数とキロバイト数で、表を拡大してください。月に約 10 万訪問までは、請求は無料枠の中か、数ドルです。それを超えると、減らさない限り、Application Insights が請求の最大の部分で、次が関数、次がアウトバウンドのデータです。

## 費用を下げるには

| 方法 | 効果 |
| --- | --- |
| `deploy --request-telemetry errors` | Application Insights のデータが 85% 減ります。成功したリクエストは、そこに表示されなくなります |
| `deploy --max-instances <n>` | 急なアクセスや悪用の最悪のケースを抑えます(既定は 20) |
| `deploy --cache-retention-days <n>` | `n` 日後に、キャッシュエントリと、古いビルドのエントリを削除します(既定は 30) |
| `/_next/static/*` を CDN から配信する | 静的ファイルを関数から外します。見積もりでは、月に数十万訪問からが効果的です。Front Door Standard の基本料金は、リスト価格で月に約 35 USD です |
| `--always-ready` を 0 のままにする(既定) | 常時稼働のインスタンスは、月に約 21 USD かかりますが、コールドスタート(2.4 秒から 0.15 秒)をなくします |

## 測定していないこと

- 実際のトラフィックでの請求額。トラフィックはスクリプトで作ったもので、実行は数分から数時間でした。
- 動的ページ、画像、Server Actions は、負荷に含めていません。
- 無料の最初の一部を超えたアウトバウンドのデータの価格と、Table Storage の価格。
